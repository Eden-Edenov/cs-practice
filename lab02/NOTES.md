Git - программа для отслеживания изменений в коде на компьютере
GitHub - это облачный сервис для проектов, которые используют git

git status - указывает текущее состояние каталога репозитория
git diff - показывает различия между разными состояниями проекта
git diff -- staged - показывает разницу между индексом и последним коммитом
